# 🎯 Number Guessing Game

A modern Python GUI-based Number Guessing Game built using Tkinter.

## ✨ Features

- 🎯 Random secret number generation
- 🎮 Three difficulty levels
- 🟢 Easy: 1–50
- 🟡 Medium: 1–100
- 🔴 Hard: 1–500
- ⬆️ Too Low / Very Close hints
- ⬇️ Too High / Very Close hints
- 🔢 Attempt counter
- 🏆 Best score tracking
- 💾 Permanent best score saving using JSON
- 🔄 New Game option
- ⌨️ Enter key support
- ❌ Exit confirmation
- 🖥️ Modern Tkinter GUI
- ⚠️ Input validation

## 🛠️ Technologies Used

- Python
- Tkinter
- JSON
- Random Module

## 🚀 How to Run

1. Make sure Python is installed.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Open the terminal.
5. Run:

```bash
python number_guessing_game.py
